# Lab Meeting - August 27, 2026

These papers trace how table structure recognition has evolved for messy, real-world images rather than clean scanned documents. The first paper introduces both the field's hardest benchmark and a detection-based baseline for it, and the ones that follow each attack a different weakness in that baseline, better boundary regression for distorted tables, bringing in the table's own text as a second signal, and pretraining the backbone on table-specific tasks before fine-tuning. Read in order they form a fairly clean line of incremental progress on the same benchmark.

## Parsing Table Structures in the Wild

Rujiao Long, Wen Wang, Nan Xue, Feiyu Gao, Zhibo Yang, Yongpan Wang, Gui-Song Xia. ICCV 2021. https://arxiv.org/abs/2109.02199

Most table structure recognition methods assume a clean, flat scan, but real photos of tables are tilted, curved, blurred, or partly hidden, and existing methods break down on them. This paper introduces WTW (Wired Tables in the Wild), a dataset of about 14,600 photographed and scanned tables spanning natural scenes, archival documents, and printed forms, covering distortions like inclination, curvature, occlusion, and overlaid tables. Alongside it, Cycle-CenterNet detects each cell by predicting its center point and four corners, then separately predicts each corner back to its neighboring cell centers, and only keeps a cell-to-neighbor link when both directions agree, an idea the authors call PairLoss that pushes disagreeing predictions to correct each other during training. On the WTW test set, the full model reaches 92.4 adjacency F1 and 83.3 TEDS, well above a plain CenterNet baseline's 58.7 TEDS, with PairLoss alone contributing roughly 9 points of that TEDS gain. Performance drops sharply on the hardest subsets, down to 51-53 TEDS on occluded, blurred, or overlaid tables, showing the dataset's distortions are still far from solved. This is really the benchmark paper for the rest of this reading set, WTW is what the later papers below are evaluated against.

## Robust Table Structure Recognition with Dynamic Queries Enhanced Detection Transformer

Jiawei Wang, Weihong Lin, Chixiang Ma, Mingze Li, Zheng Sun, Lei Sun, Qiang Huo. Pattern Recognition 144, 2023. https://arxiv.org/abs/2303.11615

Prior table structure methods either predict a pixel mask for row and column separators or regress an entire separator curve in one shot from a single query, and both approaches struggle on curved tables with large empty regions, masks fragment and one-shot curves get less reliable the farther a point sits from the query. TSRFormer's DQ-DETR instead grows each separator gradually: it finds a likely starting point near the table's center line, then adds and corrects nearby points layer by layer until the full curve is traced, so each step only has to solve a small, local placement problem instead of the whole curve at once. A second stage then merges the small grid boxes formed by these boundaries into full cells, recovering ones that span multiple rows or columns. On the WTW benchmark this reaches 94.3 F1, about 2 points above Cycle-CenterNet, though gains are smaller or absent on cleaner datasets like SciTSR and PubTabNet where boundaries are already easy to find. The authors note it still fails on extremely curved or very dense tables, where small per-step errors accumulate or cells become too small to localize individually.

## UniTabNet: Bridging Vision and Language Models for Enhanced Table Structure Recognition

Zhenrong Zhang, Shuhang Liu, Pengfei Hu, Jiefeng Ma, Jun Du, Jianshu Zhang, Yu Hu. Findings of EMNLP 2024, pp. 6131-6143. https://arxiv.org/abs/2409.13148

Purely visual table structure models can misread a cell's boundaries when the image alone is ambiguous, for instance a text-heavy cell with no visible lines. UniTabNet argues the text already inside the table is a second signal that visual-only methods ignore, and builds on a Donut-style image-to-sequence backbone to exploit it. Instead of outputting one long HTML or LaTeX string for the whole table, it first writes a short sequence of cell markers, then for each marker predicts the cell's four-corner polygon and its row and column span. Two added training signals shape that shared representation: a Vision Guider that predicts the full row and column area each cell belongs to, and a Language Guider that pulls each cell's structural representation toward the representation of the words actually inside that cell, learned jointly with a text-reading task on the same backbone. Across PubTabNet, PubTables1M, WTW, and iFLYTAB the model reaches state-of-the-art or near state-of-the-art scores on most reported metrics, including 95.1 F1 on WTW. The main practical limitation is the fixed-length output sequence, capped at 500 tokens, which cuts off cells in very large tables, and the model cannot predict row or column spans it never saw during training.

## LORE++: Logical Location Regression Network for Table Structure Recognition with Pre-training

Rujiao Long, Hangdi Xing, Zhibo Yang, Qi Zheng, Zhi Yu, Cong Yao, Fei Huang. Pattern Recognition 157, 2025. https://arxiv.org/abs/2401.01522

Many table structure methods only predict which cells are adjacent to each other, but the authors show this can look nearly correct, 84% adjacency F1 on WTW, while the actual row and column numbers assigned to each cell are wrong 57% of the time, since neighbor relationships alone don't pin down absolute position. LORE instead has every detected cell predict its exact grid address directly, a start row, end row, start column, and end column, refined in two passes so cells can use each other's first-pass estimates before finalizing. Training also penalizes two structural rules directly, that stacked cells shouldn't overlap in row number and that a cell spanning several rows or columns should predict the full span, not a truncated one. LORE++ adds a pretraining stage on 1.5 million unlabeled table images before this final training, using masked image reconstruction and a task where the model predicts how many rows and columns apart two text regions are, so the backbone learns table layout structure before ever seeing grid-address labels. On WTW this raises exact grid-address accuracy from 82.9 to 84.1 over vanilla LORE, and the gain holds even when only a fifth of the labeled training images are used. Several implementation details, like the exact pretraining sampling schedule, aren't reported, so full reproduction would need the released code.
