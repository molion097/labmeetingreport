## Location-Aware Ambient Sound Model Adaptation for On-Device Human Activity Recognition in Living Spaces

Cheolhwan Lee, Homin Kang, Soon Ju Kang. IEEE Access 2025. https://doi.org/10.1109/ACCESS.2025.3568828

Sound-based activity recognition suits homes because it is non-intrusive, but a model trained on a pre-collected dataset degrades when installed in a new room, since the acoustics and the relevant sounds change from place to place. This paper proposes an adaptive ambient sound system for edge devices with three parts. The classification labels can be customized per installation, so each home only uses the activity classes that make sense there. A pre-trained sound model is fine-tuned on the device with locally collected data, a transfer learning step meant to absorb the domain shift. A pseudo-labeling loop then keeps refining the model by retraining on its own high-confidence predictions for unlabeled audio, so long-term adaptation needs little manual annotation. The authors implemented the system and tested it on real recordings from several residential environments. I could only retrieve the abstract, so this summary relies on it alone and has no specific accuracy or latency numbers. It reports only that the system adapted across locations while keeping accuracy high, inference real-time, and training time short. The on-device design is the practical appeal, but the numbers and baselines need checking in the paper.
